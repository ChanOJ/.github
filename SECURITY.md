## Reporting a vulnerability

Please report privately through GitHub private vulnerability reporting: open the **Security** tab
of the affected repository and choose **Report a vulnerability**. Do not open a public issue for
a security problem.

Removal requests (content, names, links) can be sent the same way.

## Reporting a bug

For anything that is not a security problem (broken page, link, image or sound), open a public
issue in the affected repository: **Issues** tab, then **New issue**. Please give the page
address, your browser, what you expected and what happened. Some oddities come from the original
site and are kept on purpose.

Do not put personal data in an issue.
