# Security policy

These repositories are static archives of websites made between 1997 and 2006. They have no
server-side code, no accounts and no user data.

## Reporting a vulnerability

Please report privately through GitHub private vulnerability reporting: open the **Security** tab
of the affected repository and choose **Report a vulnerability**. Do not open a public issue for
a security problem.

Removal requests (content, names, links) can be sent the same way.
